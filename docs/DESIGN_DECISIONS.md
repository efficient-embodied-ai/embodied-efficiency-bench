# EmbodiedX Architectural Design Decisions (v1.0.0)

**Status:** Locked on October 30, 2026 for Season 1 launch at the CoRL 2026 EEAI Workshop ([`https://efficient-embodied-ai.github.io/challenge/`](https://efficient-embodied-ai.github.io/challenge/)).  
**Scope:** Closed and Open Divisions across Track 1A (`pi0.5-LIBERO`), Track 1B (`GR00T N1.7-3B`), and Track 2 (`Cosmos-Predict2.5-2B`) on two standardized single-chip cloud accelerators (`NVIDIA L40S 48 GB` / `nvidia_l40s_48gb` and `Google Cloud TPU v6e-1 32 GB` / `tpu_v6e_1_32gb`), opening with `0` organizer-seeded vendor benchmark entries.

## Locked Season 1 Decisions (`D1` to `D10`)

| ID | Architectural Decision | Rationale |
| :--- | :--- | :--- |
| **D1** | **Closed and Open Divisions Under Locked Execution Horizon `K_eval` and Host-CPU Offload Ban.** Both divisions strictly lock execution horizon `K_eval` across all entries (`K_eval = 5` on Track 1A, `K_eval = 8` on Track 1B, `K_eval = 16` predicted frames per rollout prediction on Track 2) so aggregate `Actions/s` or `Predictions/s` cannot be inflated by lengthening open-loop horizons. In both divisions, `100%` of neural forward-pass operators (`MatMul`, `Attention`, `Conv`, `MLP`, `VAE`, text encoders) inside timed `act()` and `rollout()` calls must execute on the single target accelerator; host CPU threads handle I/O, tokenization, orchestration, and action queuing only, while frozen episode prompt embeddings may be pre-cached on the target accelerator during untimed `reset()`. **Closed Division** fixes checkpoint architecture, weights, and solver step count under BF16/FP16/FP8 numerics verified by inline Golden-IO parity (`--num-samples >= 100` real trace samples with mean and `CVaR-1%` worst-tail floors) and forbids pseudo-causal sub-clip frame slicing (`stream_chunk_frames > 0`) on Track 2. **Open Division** allows INT4 quantization, pruning, step distillation, or token merging when paired with a signed Stage-2 quality receipt (`LIBERO-RT` within `-5.0 pp` for Track 1; `SSIM >= 0.88`, `PSNR >= 26.0 dB`, `CVaR-1%(SSIM) >= 0.80`, `CVaR-1%(PSNR) >= 22.0 dB`, `LPIPS <= 0.12`, `FVD <= 120`, `InvDyn >= 0.99`, and `Kendall tau >= 0.80` for Track 2). | Separates lossless numerical/kernel engineering (`Closed`) from algorithmic compression (`Open`) while closing variable-`K_eval` and host-CPU offload loopholes. |
| **D2** | **Three Separate Track Pools Anchored to Gapless Real-Time SLAs, Live Checkpoints, and Public Real-World Traces.** At a `20 Hz` robot control loop (`dt = 50 ms`, where `20.0 Chunks/s` is the single-tick reaction ceiling), executing `K_eval` steps spans `K_eval * dt`. All evaluation frames come deterministically from public `HuggingFaceVLA/libero` (commit `86958911c0f959db2bbbdb107eb3e17c5f9c798e`) and `lerobot/droid_100` (commit `87301a2d2e99340e2010c9ef0f1d8e780b08aaf9`), with zero synthetic sine-wave traces allowed in submissions:<br>• **Track 1A (`pi0.5-LIBERO`):** Physical Intelligence `pi0.5` loaded from canonical ungated checkpoint `lerobot/pi05_libero_finetuned_v044` (commit `7152f13e34c6c115d808aea0e5d08aca74eac14b`, with pre-fit normalizers; 10 Euler ODE steps, dual `224x224` RGB `HuggingFaceVLA/libero` traces, `H = 10`, locked `K_eval = 5`, `~0.734 TF/action`), gapless SLA **`p99 <= 250.0 ms` (`>= 4.0 Chunks/s`)**. Both `PyTorch` (`CUDA`/`TorchTPU`) and `openpi` `JAX` are certified reference runtimes.<br>• **Track 1B (`GR00T N1.7-3B`):** NVIDIA `GR00T N1.7-3B` loaded from `nvidia/GR00T-N1.7-LIBERO` (`libero_10` checkpoint, commit `2ea293aa20ba7cf5bbf3ba17a5fbcb1a01cbfe21`; Cosmos-Reason2-2B VLM + 16-step DiT flow action head, dual `256x256` RGB `HuggingFaceVLA/libero` traces, `H = 16`, locked `K_eval = 8`, `~0.404 TF/action`), gapless SLA **`p99 <= 400.0 ms` (`>= 2.5 Chunks/s`)**.<br>• **Track 2 (`Cosmos-Predict2.5-2B`):** NVIDIA `Cosmos-Predict2.5-2B` loaded from `nvidia/Cosmos-Predict2.5-2B` (`robot/action-cond` action-conditioned checkpoint, commit `85f8ae7bfe8f5525c8d103429524dcf12f98bf7b`; 2B bidirectional 3D-DiT, 10 steps, `CFG = 1.0`, `256x256` RGB `lerobot/droid_100` manipulation rollout traces, locked `K_eval = 16` predicted frames per rollout prediction), gapless SLA **`p99 <= 1000.0 ms` (`>= 1.0 Pred/s`)**. | Separates Track 1A and Track 1B awards to eliminate a `1.82x` FLOPs-per-action bias, pins immutable public checkpoint and dataset commit SHAs, and sets physically exact non-starvation control deadlines for each horizon. |
| **D3** | **Quality Verification as a Hard Admissibility Gate.** Quality is enforced as a pass/fail gate against golden parity sets of `--num-samples >= 100` real trace samples.<br>• **Closed Gate (Same-Run Inline):** Native wire image resolution (`>= 224x224` on Track 1A, `256x256` on Tracks 1B and 2), action `CosSim >= 0.995` plus `CVaR-1%` worst-1% tail floor on Track 1, and rollout `SSIM >= 0.88`, `PSNR >= 26.0 dB`, `CVaR-1%(SSIM) >= 0.80`, and `CVaR-1%(PSNR) >= 22.0 dB` on Track 2 against BF16 golden outputs, plus BF16-safe `G4` input-perturbation sensitivity.<br>• **Open Gate (Signed Stage-2 Receipt):** Track 1 requires latency-coupled `LIBERO-RT` closed-loop success within `-5.0 pp` of the BF16 reference under actuation delay `d = ceil(L / dt)`. Track 2 requires `SSIM >= 0.88`, `PSNR >= 26.0 dB`, `CVaR-1%(SSIM) >= 0.80`, `CVaR-1%(PSNR) >= 22.0 dB`, `LPIPS <= 0.12`, `FVD <= 120`, inverse-dynamics action consistency `InvDyn >= 0.99`, and policy-ranking correlation `Kendall tau >= 0.80`. | Guarantees functional control and rollout fidelity before any latency, throughput, or energy figure is admitted to the frontier. |
| **D4** | **Ordered Discrete Grid Sweep, Pooled Tail Latency, Fairness Fence, and Stock-TDP Thermal Discipline.** Contestants evaluate one engine across the canonical ordered concurrency grid `C in {1, 2, 4, 8, 16}` starting at `C = 1`. Only monotonic tail truncation on device OOM is permitted; off-grid concurrencies and curve interpolation are rejected.<br>• **Pooled Steady-State `p99(C)` and Fairness Fence:** Each point measures pooled steady-state `p99(C)` across active slots over `N >= 320` chunks/run on Track 1 (`VLA`) or `N >= 200` predictions/run on Track 2 (`WM`) while untimed keep-alive requests maintain full concurrency, paired with a mandatory `<= 15%` per-slot completion fairness fence blocking LIFO slot starvation.<br>• **Trial Count plus Variance and Clock Discipline:** Every grid point requires `N = 3` trials within `<= 8%` inter-run `p99` spread (`<= 5%` on `p50` and throughput) and unimodal `p99 / p50 <= 1.5` at `C = 1`. Warm up on the real model workload (`--warmup >= 30`) at stock vendor boost clocks and stock board TDP first; lock GPU SM clocks via `nvidia-smi -lgc` (calibrated directly on the live model loop instead of synthetic GEMM burners) only when dynamic boost trips the variance gate. Above-stock TDP or clock overrides are banned. | Keeps high-concurrency `p99(C)` statistically well-conditioned without slot starvation, artificial GEMM-burner underclocking, or curve interpolation. |
| **D5** | **Disambiguated Interactivity and Fleet Throughput Axes.**<br>• **X-Axis (Guaranteed Interactivity, Right is Faster):** `X(C) = 1000 / L_p99(C)` reported in `Chunks/s` (Track 1) or strictly `Predictions/s` (Track 2, with locked `K_eval = 16` frames per rollout prediction), replacing ambiguous bare `"Hz"` conventions across VLA papers.<br>• **Y-Axis (Fleet Throughput and Energy Efficiency, Up is Higher):** Primary view plots steady-state wall-clock `Actions/s` (`N_timed * K_eval / T_steady`, Track 1) or strictly `Predictions/s` (`N_timed / T_steady`, Track 2). Efficiency view plots hardware-measured `Actions/J` or `Predictions/J` (`power_provenance == "MEASURED"` from constant-cap `10 Hz NVML` board power on `L40S`; `TPU v6e-1 = N/A`). Schema diagnostics also record reference `$/hr` rate and Roofline `Iso-Compute` (`per 100 Dense BF16 TFLOPS`) / `Iso-Bandwidth` (`per TB/s`). | Adapts SemiAnalysis InferenceX Pareto visualization to action-chunked policies and world models without unit ambiguity. |
| **D6** | **Forward-Only Asynchronous Closed-Loop Timing in `LIBERO-RT`.** During `LIBERO-RT` Stage-2 evaluation at `dt = 50 ms`, physics advances `d = ceil(L / dt)` steps asynchronously while the accelerator computes. Forward-only overlap (or closed-form `SEAM` boundary blending) runs by default without forcing test-time `IT-RTC` `vjp` backpropagation (`+27%` latency overhead). | Models real-time actuation delay accurately while remaining compatible with static `TorchTPU`, `XLA`, and `TensorRT` execution graphs. |
| **D7** | **Co-Reported Control Diagnostics at Every Sweep Point.** Alongside `X(C)` and `Y(C)`, every point logs Peak Age of Information `PAoI = L_p99(C) + (K_eval - 1) * dt` (`ms`), latency tail ratios `p99 / p50` and `max / p50`, per-slot completion fairness skew (`<= 15%`), normalized action jerk (Track 1), `TTFF_p99` (`== L_clip` for bidirectional 3D-DiTs on Track 2), and peak accelerator memory (`GB`). | Captures worst-case sensor-to-actuator staleness, jitter smoothness, slot fairness, and memory footprint inside each receipt. |
| **D8** | **Two Standardized Season 1 Cloud Hardware Targets (`num_devices == 1`).** Every entry runs on one physical chip (`num_devices == 1`, `TP = PP = EP = 1`):<br>1. **Standard GPU (`nvidia_l40s_48gb`):** `NVIDIA L40S` (`48 GB` GDDR6, Ada SM89, `350 W` TDP, native FP8, `362.05 TF` dense BF16, `10 Hz NVML` board power; available on Shadeform `~$0.88-$1.15/hr`, AWS EC2 `g6e.xlarge`, or NVIDIA Academic Grant Program).<br>2. **Standard TPU (`tpu_v6e_1_32gb`):** `Google Cloud TPU v6e-1` (`32 GB` HBM2e, Trillium, `918 TF` dense BF16, isolated via `TPU_CHIPS_PER_HOST_BOUNDS=1,1,1 TPU_HOST_BOUNDS=1,1,1 TPU_VISIBLE_DEVICES=0`; available on Google Cloud `~$1.375/hr` or free via Google TPU Research Cloud / TRC).<br>Additional single-chip and edge profiles remain in the schema solely for local prototyping and future onboard-edge seasons. | Centers Season 1 on two affordable, cloud-accessible single-chip targets so finalists can be re-run cleanly on identical organizer hardware. |
| **D9** | **Three Scalar Awards per Track, Hypervolume Tie-Breaker, and Option A Neutral Launch.** Season 1 opens October 30, 2026 with `0` organizer-seeded vendor numbers. Each track evaluates three official scalar categories: (1) **Interactive Reactivity (`C = 1`)** (`1000 / p99_ms` at `C = 1`, tie-broken by lowest `p50_ms`, requiring `p99 / p50 <= 1.5`), (2) **Real-Time Fleet Throughput** (highest SLA-compliant `Actions/s` or `Predictions/s`), and (3) **Green Embodied Efficiency** (highest `MEASURED` `Actions/J` or `Predictions/J` via constant-cap `10 Hz NVML` board power on `L40S`; `--assume-power-watts` rejected; `TPU v6e-1 = N/A`). Exact ties break via lower-step Real-Time Dominated Hypervolume wrt `(0.5 * X_SLA, 0)` over SLA-compliant points in `{1, 2, 4, 8, 16}`. Checkpoint 1 (`Nov 10, 2026 23:59 UTC`) feeds the live Nov 12 CoRL spotlight in Austin; Checkpoint 2 (`Dec 18, 2026 23:59 AoE`) selects Official Season 1 winners (monetary prizes, CoRL 2026 EEAI Workshop Award Certificate, invitation to apply for Google Cloud credits, and *Season 1 Systems Report* co-authorship). | Resolves crossing Pareto curves cleanly, forbids assumed-wattage guesses, and preserves strict multi-vendor neutrality at launch. |
| **D10** | **Cryptographic Micro-Jitter, Eight-Gate Anti-Gaming Verification, and Two-Phase Commit-Reveal.** Requests carry opaque `UUIDv4` `session_id`s, native wire-resolution RGB payloads drawn from public `HuggingFaceVLA/libero` and `lerobot/droid_100` datasets, and dynamically seeded per-frame `+-1/255` `uint8` pixel micro-jitter, paired with an outlier fence `max / p50 <= 4.0`, the `<= 15%` per-slot completion fairness fence, and inline blind Golden-IO (`>= 100` samples) + `G4` perturbation canaries to defeat trace memoization and selective cache bypass. Phase-1 public PRs (`eeb prepare-commit-bundle` + `eeb verify-bundle --strict`) submit only `bundle_summary.json` and `submission_meta.json` committing `recipe_commit_sha256` over canonical `reveal_manifest.json` (pinning OCI `@sha256`, HF checkpoint commit SHA and shard SHA-256s, lockfile SHA-256, and CLI command). Within `24h` after Dec 18 (`23:59 AoE`), shortlisted finalists (`<= 1` per lab per track and division) privately supply matching containers; final awards are ranked strictly by Phase-2 organizer clean-hardware re-runs on a private held-out split (`+/- 8%` vs. Phase 1 acts strictly as an anti-fraud DQ gate). | Protects frontier IP prior to contest freeze while guaranteeing tamper-evident hardware reproducibility for official awards. |
